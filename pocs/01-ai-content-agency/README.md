# ✍️ AI 콘텐츠 대행 서비스 (POC)

한국 중소기업(SMB)을 위한 AI 기반 콘텐츠 대행 서비스 프로토타입입니다.

## 📋 개요

- **타겟**: 마케팅 리소스가 부족한 한국 중소기업
- **핵심 가치**: AI를 활용하여 블로그, 상품 설명, 광고 카피를 빠르고 합리적으로 제작
- **형태**: 단일 페이지 애플리케이션 (SPA) POC

## 🚀 주요 기능

| 기능 | 설명 |
|------|------|
| **AI 콘텐츠 생성** | 주제 입력 시 블로그/상품설명/광고카피 시안 생성 (데모). 200자 제한, 입력 오류 안내, 복사, 다른 시안 뽑기 |
| **시안 보관함** | 생성한 시안을 이 브라우저(localStorage)에 최근 8건까지 보관, 다시 열기·지우기 |
| **시안 → 주문** | "이 시안으로 주문하기"로 대시보드에 대기중 주문 생성 (ORD-연도-번호) |
| **포트폴리오** | 업종별 콘텐츠 제작 사례 갤러리 (유형 필터) |
| **요금제** | 스타터/프로/엔터프라이즈 3단계 플랜. 선택하면 대시보드에 월 주문 한도 표시, 한도 초과 주문 차단 |
| **대시보드** | 상태별 집계 겸 필터, 주제·주문번호 검색, 진행 단계 표시, 데모 주문으로 되돌리기 |

## 📁 파일 구조

```
01-ai-content-agency/
├── index.html          # 페이지 구조
├── style.css           # 디자인 시스템 ("시안 테이블", DESIGN.md 참고)
├── core.js             # 데이터와 순수 로직 (DOM 없음)
├── app.js              # 화면 렌더링과 이벤트 (ES module)
├── assets/             # 키 비주얼, 빈 상태 이미지, OG 이미지, 파비콘 (출처: docs/asset-register.md)
├── tests/              # core.js 단위 테스트 (node:test)
├── PRODUCT.md          # 제품 맥락
├── DESIGN.md           # 디자인 시스템
└── README.md           # 이 파일
```

## 💻 실행 방법

ES module을 쓰므로 로컬 서버로 여세요 (파일을 직접 열면 모듈이 로드되지 않습니다).

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

테스트 (저장소 루트에서):

```bash
node --test pocs/01-ai-content-agency/tests/*.test.mjs
```

## 🛠 기술 스택

- **HTML5 / CSS / Vanilla JavaScript** — 빌드 없음, 프레임워크 없음
- **글꼴** — Hahmlet (Google Fonts), Pretendard (jsDelivr)
- **localStorage** — 시안 보관함, 주문, 선택한 요금제 저장 (저장이 막힌 브라우저에서도 동작)
- **모바일 퍼스트** — 반응형 디자인 (320px~), 키보드 조작, 움직임 줄이기 설정 지원

## 📌 참고 사항

- 이 프로젝트는 POC(Proof of Concept)이며, 실제 AI API 연동 없이 템플릿 기반으로 콘텐츠를 시뮬레이션합니다.
- 통계 수치, 포트폴리오 사례, 주문 현황은 모두 데모 데이터입니다.
- 프로덕션 전환 시 백엔드 API, 사용자 인증, 결제 시스템 연동이 필요합니다.
